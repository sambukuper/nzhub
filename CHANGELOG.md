# NZHub 1.0.0

Первая сборка форка. Взяли Happ 4.9.0 (ядро Xray 26.10) и пересобрали под своим именем.

Что изменилось:

- Приложение переименовано в NZHub, идентификатор пакета `com.nzboost.nzhub` — можно держать рядом с оригинальным Happ, конфликтов при установке не будет.
- Все иконки заменены на монохромный знак NZ: лаунчер во всех плотностях, адаптивные иконки с монослоем для Android 13+, значок уведомлений, баннер для TV.
- Тем 12 штук плюс вариант «как в системе»: Light, Dark, AMOLED Black, Midnight Blue, Forest, Sunset, Ocean, Rose, Lavender, Mono, High Contrast, Cyberpunk. Выбор в настройках применяется сразу, без перезапуска; каждая палитра проверена по WCAG AA.
- Обновления ходят на GitHub Releases этого репозитория: проверка при запуске (не чаще раза в 6 часов), кнопка «Проверить обновления» в настройках, окно с описанием релиза и установка прямо из приложения. Без сети, при лимитах GitHub или пустом списке релизов просто сообщаем, что не удалось.
- Sentry, Firebase и отчёты Happ вырезаны. Аналитика не отправляется никуда.

Известные ограничения: это пересобранный декомпилированный APK, поэтому доработки идут на уровне ресурсов и smali, а не исходников на Kotlin.
